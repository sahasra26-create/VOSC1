# VOSC Activity-1 – Tic-Tac-Toe

A two-player Tic-Tac-Toe game built with HTML, CSS, and JavaScript.

## How to Run
Download or clone this repo and open `index.html` in your browser.

## How to Play
- Player X goes first, then O. Click an empty cell to place your mark.
- Get three in a row (horizontal, vertical, or diagonal) to win.
- If all 9 cells fill up with no winner, it's a draw.
- Use **New Round** to play again or **Reset Scores** to start over.

## Files
- `index.html` – layout
- `style.css` – styling
- `script.js` – game logic
